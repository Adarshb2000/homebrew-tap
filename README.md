# Adarshb2000/homebrew-tap

Personal Homebrew tap.

## ai-note-taker

Local AI meeting note-taker for macOS (Apple Silicon). Watches for meeting-app
mic activity, records both sides of the call via Core Audio process taps, then
transcribes, diarizes, and summarizes — entirely on-device.

```bash
brew install Adarshb2000/tap/ai-note-taker
```

Then run `ai-note-taker` (or `brew services start ai-note-taker` for autostart).
See the [main repo](https://github.com/Adarshb2000/good-freaking-note-taker)
for setup details, permissions, and limitations.
